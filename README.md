# Starbie-Project-with-Half-life

This is a tiny motion-controlled digital figure or sprite that reacts to its environment.

Depending on which direction the PCB is facing, the digital character acts in a different way.
There are a bunch of different emotions and reactions it has and it can all be changed and coded differently as well.

I used Arduino IDE to code this project and designed it in KiCad.
